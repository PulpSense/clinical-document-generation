# Use explicit client authorities for every DOCX template family

Every supported Protocol branch derives its Layout Contract from `HJS-23-01 Protocol 16Sep2023.docx`; the Advarra ICF family derives its Layout Contract and Client ICF Language from `HJS-23-01 ICF v1 26Sep2023.docx`; and the Sterling family derives them from `Consent Template with merge fields for GCP.effective 10.27.25.CLEAN.docx`. Generated documents may paginate naturally and may extend the source structure only by cloning its established Word patterns; they must not switch to generic formatting, compress required content to preserve pagination, copy study-specific facts, or default a missing version from an example.

Authority-derived hierarchy is source-bound: an optional heading and its body are omitted together when the Canonical Approved Source supplies no lawful content for that section. This omission prevents a bare heading while preserving the authority's ordering and Word design for every emitted section.
