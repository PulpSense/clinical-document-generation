# Hermes Extraction Boundary

Hermes/model reasoning owns the Extraction Pass from a Source Intake Packet into a Draft Reference, because messy clinical source material can arrive as one Markdown file, many files, or mixed document evidence that is too variable for a deterministic local parser. Scripts own source preservation, branch-specific Required Source Input gates, Source-of-Truth Markdown approval, structural rendering, delivery validation, and smoke-test evidence so generated Protocol, ICF, and PRS XML outputs remain auditable and fail safely.
