# Make generation reproducible through immutable run revisions

Each Run Revision records one immutable source-approval identity. Its current Generation Authority Attempt records a Generation Manifest binding the approved source, contracts, boilerplate, templates, model, renderer, drafts, evidence, and final artifact hashes. Changing generation authority without changing approved source retains approval but archives the complete prior attempt under a hash-inventoried immutable identity before beginning another attempt. Repeating generation with unchanged inputs reuses accepted Section Drafts unless an explicit redraft is requested; changing the approved source creates a new revision and invalidates prior approval and drafts. Run evidence is retained internally until explicitly removed, and only the newest passing attempt of the newest revision is client-facing.
