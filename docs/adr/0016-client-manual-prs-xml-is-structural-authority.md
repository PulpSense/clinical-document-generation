# Use the client manual PRS XML as the structural authority

The client-approved `CB-26-01_manual.xml` is the PRS XML Structural Reference for element names, major ordering, optional empty nodes, and the distinction among intervention, arm, primary, secondary, and other-outcome blocks; its study-specific values and repeated-block counts must not leak into another study. Generated repetition is driven by the Canonical Approved Source while preserving the manual reference's element taxonomy and ordering. `CB-26-01 XML_generated.xml` is a negative regression fixture because it omits much of that shape and changes repeated-block taxonomy. The narrow PRS drafting batch supplies only the brief and detailed descriptions, while deterministic Python owns the structural mapping and must match the client-approved reference contract before release.
