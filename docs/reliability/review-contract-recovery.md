# Review contract and narrative schedule recovery

The October 9 blocked-run replay showed a shared failure chain: generated KEY INFORMATION text existed, but the summary's section ID did not resolve to its retained heading. Review requests therefore contained an empty passage while demanding an exact passage quotation. The completed reviewer response also identified genuine table defects. Resolution metadata validation rejected that response at ingestion, discarding the table findings before construction recovery. The Desktop operation repeatedly dispatched the identical request until its deadline.

The table defects came from another shared boundary: an approved list of visit-name strings was ignored by visit normalization. Rendering fell back to splitting assessment prose on commas, breaking medical descriptions and joining unrelated phases. Both Protocol tables now consume the explicit visit inventory, including string lists. Unallocated assessment prose remains verbatim evidence; code does not infer activity assignments or timing from punctuation.

The fixes separate response consumption from approval. An authenticated, otherwise valid review with resolution metadata errors is retained for recovery. Substantive findings reach their repair owner; metadata errors reach the reviewer with specific correction feedback. Neither response consumption nor a repair grants publication approval. Completeness, clinical findings, artifact identity, and fresh final review still apply.

Missing caution passages fail before worker dispatch and return to construction. Content handoffs carry their request identity, as visual handoffs already did. Persisted recovery history counts attempts for each request and normalized set of validation errors, retaining error multiplicity. Changed errors or fewer unresolved errors permit another correction; reordering the same feedback does not. Repeated or cycling feedback retains its earlier counts across process restarts, then reports `handoff_no_progress` after one retry of that failure state. A new candidate review has a separate request identity and history. This transport guard does not limit clinical repair attempts or renew the operation deadline.

Regression coverage uses synthetic inputs and the actual rendering, response-ingestion, recovery, and publication boundaries. It includes all applicable ICF sections in both templates and study branches, varied visit inventories, invalid metadata with substantive findings, metadata-only retry, construction repair followed by independent recheck, forged identity, missing evidence, and unchanged versus new requests. The original captured response now reaches recovery instead of being discarded. Controlled rendering and reviewer doubles verify workflow behavior; they do not certify live clinical judgments or Linux rendering. Installation assurance and Linux dependencies remain unchanged. Full-suite and live Linux release validation remain separate approved activities.

The missing-passage finding is constructed in the inventoried `_review_evidence_finding` function, declares its blocking disposition and construction owner, and has paired valid/invalid evidence in the developer audit. A mutation regression confirms that changing its repair routing changes the audit fingerprint.

## Shared output projections

Review of the subsequent successful document set exposed assembly defects that
prose retries cannot correct: the renderer read legacy top-level references but
missed canonical `study.references`; Advarra and Sterling used different count
display paths; PRS treated an honorific as a given name, missed singular site
investigators, and converted an absent group inventory to zero. Protocol and PRS
also used different short-title fallbacks. These are shared mapping failures,
not evidence that the study needs another wording rule.

Both title destinations now use one contract projection. Count display is shared
by both consent families and the Protocol shell. Canonical references reach a
numbered Protocol bibliography, with a construction-owned omission check;
participant-facing ICF prose retains clinical qualifications while removing
resolvable numeric citation markers. Missing citation sources stay visible for
review. Multiline entries keep one citation number. Exact legacy sample-count
records repeated in AI drafts receive the same display conversion as shell
fields. PRS respects supplied person components,
removes recognized honorifics from fallback names, accepts both site-investigator
representations, and keeps an unknown observational group count blank. Explicit
cohorts still determine the actual groups and links.

Tables retain every supplied timing and assignment. An entirely empty optional
timing/window column is omitted; partial columns remain. Inventory rows use body
styling consistently instead of inheriting the authority's second header row.
Legacy unallocated prose remains intact rather than acquiring guessed visits.
For new inputs, the Extraction Pass structures explicit narrative relationships
before approval and previews the computed assessment table. This distinction
preserves approval while making new sources useful to every downstream surface.
Absent optional privacy and operational policies remain input limits.

Focused regression coverage assembles all five supported branch/template
combinations, varies narrative and structured schedules, and pairs faithful
outputs with deleted bibliography, moved assessment assignments, and corrupted
XML identities/counts. It also preserves meaningful negatives, compound supplied
names, qualified follow-up anchors, and unsupported count shapes. These are
deterministic assembly and mutation checks; they do not substitute for independent
model review, Linux host rendering, installation assurance, or live complete-set
delivery evidence. Future unknown clinical defects still require the governed
review and repair workflow rather than a promise that no new defect can occur.

The captured-source assembly replay moves from five reproduced defects to zero
with the original input and extracted document passages. It is private debugging
evidence, not a fresh clinical review or publication approval. Synthetic DOCX
outputs render for all five combinations; changed table, bibliography and count
surfaces receive local visual checks. Packaging tests require a clean committed
snapshot and are separate from these assembly fixtures.
