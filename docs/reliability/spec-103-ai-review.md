Code does not decide whether two clinical representations conflict. The `awaiting_approval` status remains a preparation result, not proof that AI performed this assessment.

Source review returns an explicit `review_delivery.link` and `source_review_reply` with the actual editable-file attachment and approval message. Attach/upload the file through the channel; preserve a clickable accessible link in chat. A host-local path that the user cannot access needs the channel's upload mechanism. This closes the previous path-only payload gap; it does not establish the cause or resolution of a particular live Hermes omission.

Section prompts identify purpose, evidence, ownership and relationships across Protocol, selected ICF and PRS; length goals remain advisory. Applicable template insertion is deterministic. The content reviewer opens actual hash-bound native files, including tables, headers/footers, text boxes and XML values, rather than trusting the construction model. Missing section passages reach review as missing-content anchors. Content and document-scoped page review requests are produced together and use the existing concurrent worker wave. Every rendered page remains individually assessed.

Source-routing obligations remain useful evidence context; a separate fact-by-fact response is no longer mandatory. Normal independent assessments and actual findings carry the judgment. Ordinary style preferences require no repairs or client warning. Finding handoff preserves its complete original response evidence for the general repair integration in #106.

`create_verification_requests(review_context=...)` optionally binds real prior findings and repair-author evidence to fresh requests through the existing ledger/hash. `review_context.prior_findings` carries stable `finding_id`, artifact and targets (raw findings or their `verification_source_finding`). The independent reviewer cites each substantive concern ID in the relevant existing assessment notes with its reassessment, or retains it as a finding. A silent generic pass is incomplete. This is concern continuity, not a per-rule adjudication schema; #106 supplies context and stable IDs for older visual findings that lack them.

Focused tests use controlled reviewer/render adapters, proving source handoff, branch lifecycle, malformed/stale review rejection and concern continuity.
